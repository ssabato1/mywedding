예산표를 처음 만들 때 흔히 항목마다 금액부터 적습니다. 그러면 견적을 받을 때마다 표 전체가 흔들립니다. 해외 가이드들이 권하는 방법은 반대입니다. 전체를 100으로 놓고 항목별 비율을 먼저 정한 다음, 금액은 나중에 채웁니다. 이 글에서는 금액 없이 비율과 순서만 다룹니다.

## 해외 조사에 나타난 항목별 비중

The Knot의 [예산 가이드](https://www.theknot.com/content/wedding-budget-ways-to-save-money)는 미국 커플의 실제 지출을 바탕으로 다음과 같은 비중을 제시합니다.

| 항목 | 비중 |
| --- | --- |
| 베뉴(장소) | 29% |
| 식사·음료 | 24% |
| 사진·영상 | 10% |
| 플라워·장식 | 9% |
| 음악 | 6% |
| 드레스·예복 | 6% |
| 반지 | 5% |
| 플래너 | 4~5% |
| 엔터테인먼트 | 3% |
| 이동 수단 | 2% |
| 청첩장·인쇄물 | 1% |
| 주례·진행 | 1% |

장소와 식사가 절반을 넘습니다. 나머지 항목을 아무리 줄여도 이 두 가지가 정해지면 예산의 윤곽이 정해집니다.

## 한국 예식에 옮길 때 달라지는 것

미국의 비율을 그대로 쓸 수는 없습니다. 구조가 다르기 때문입니다.

- **식사 비중이 더 큽니다.** 한국은 하객 수가 많고 식대가 인원에 비례하므로, 장소와 식사를 합친 비중이 미국보다 높게 나오는 경우가 많습니다.
- **대관료와 식대가 묶여 있습니다.** 많은 홀이 대관료, 식대, 기본 연출을 한 견적서로 냅니다. 항목을 나눠 보려면 견적서의 줄을 하나씩 확인해야 합니다.
- **플래너 항목이 다릅니다.** 해외의 플래너 비용 자리에 한국에서는 스튜디오·드레스·메이크업 패키지가 들어옵니다.
- **보증인원이 기준입니다.** 실제 참석 인원이 아니라 계약한 보증인원으로 식대가 계산됩니다.

## 예비비: 처음부터 떼어 놓는다

The Knot은 최소 5%를 예비로 두라고 권하고, Joy의 [예산 비율 가이드](https://withjoy.com/blog/wedding-budget-breakdown-by-percentage/)는 5~10%를 제시합니다. 이 블로그에서는 10%를 권합니다. 한국 예식에서는 보증인원 변동, 당일 추가 식수, 플라워 추가, 연장 요금처럼 뒤늦게 생기는 항목이 적지 않기 때문입니다.

예비비는 남는 돈이 아니라 처음부터 떼어 놓는 항목입니다. 전체를 100으로 잡았다면 90으로 계획을 세우고 10은 건드리지 않습니다.

## 순서: 우선순위 세 가지를 먼저 고른다

The Knot의 가이드가 권하는 방법은 두 사람이 각자 가장 중요한 항목 세 가지를 적는 것입니다. 겹치는 항목에 비중을 더 주고, 겹치지 않는 항목에서 줄입니다.

1. 전체 예산의 상한을 정합니다. 양가 지원이 있다면 범위와 시점을 먼저 확인합니다.
2. 예비비 10%를 떼어 둡니다.
3. 우선순위 세 가지를 고릅니다.
4. 장소와 식사의 견적을 먼저 받습니다. 이 두 항목이 정해져야 나머지 비율이 나옵니다.
5. 견적은 부가세와 봉사료를 포함한 **최종 금액**으로 비교합니다. Joy의 가이드도 세금과 수수료가 들어간 금액으로 보라고 강조합니다.
6. 계약할 때마다 표를 고칩니다.

## 한국에서 적용할 때 확인할 조건

| 확인할 것 | 왜 중요한가 |
| --- | --- |
| 견적서에 부가세가 포함되어 있는지 | 포함 여부에 따라 총액이 10% 달라집니다 |
| 최소 보증인원과 초과·미달 시 계산 방식 | 식대는 실제 인원이 아니라 보증인원 기준입니다 |
| 대관료에 포함된 것과 별도인 것 | 플라워, 음향, 영상, 연출이 어디까지 기본인지 |
| 요일·계절·시간대에 따른 차이 | 같은 홀도 날짜에 따라 조건이 달라집니다 |
| 계약금·잔금 일정과 취소 규정 | 지출 시점을 달력에 옮겨 두어야 합니다 |
| 연장·추가 요금이 생기는 조건 | 예비비가 실제로 쓰이는 지점입니다 |

요즘은 날짜와 인원, 옵션을 고르면 항목별 금액을 바로 보여 주는 셀프 견적서를 두는 홀도 있습니다. 견적을 받기 전에 비율표를 먼저 만들어 두면 숫자를 비교하기가 한결 쉽습니다.

## 요약

- 예산은 금액보다 비율로 먼저 짭니다. 장소와 식사가 절반을 넘습니다.
- 한국에서는 식사 비중이 더 크고, 보증인원이 계산의 기준입니다.
- 예비비 10%는 처음부터 떼어 놓고, 견적은 부가세 포함 최종 금액으로 비교합니다.
