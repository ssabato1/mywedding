결혼 예산은 항목별 희망을 더하는 방식보다 전체를 100%로 고정하고 예비비 10%를 먼저 떼어 두는 방식이 관리하기 쉽습니다.

![넓은 예식 공간은 장소뿐 아니라 기본 장비·설치·철거 범위까지 하나의 항목으로 확인해야 합니다](/images/convention-wedding-01.jpg)

## 해외 자료의 비중은 왜 서로 다른가

The Knot의 [Wedding Budget Breakdown](https://www.theknot.com/content/wedding-budget-ways-to-save-money)은 실제 커플 조사에 기반해 장소·대여 29%, 식음료·케이크 24%, 사진·영상 10%, 꽃·장식 9% 등 세부 비중을 제시합니다. Brides의 [Wedding Budget Breakdown](https://www.brides.com/story/wedding-budget-guide-allocating-funds-staying-on-track)은 장소·케이터링을 35%로 묶고 플래닝 12%, 사진·영상·콘텐츠 10%, 장식 10% 등 계획용 기준을 제안합니다.

Zola의 [Wedding Cost Index](https://www.zola.com/expert-advice/zola-wedding-cost-index)는 장소·케이터링 30~50%, 사진·영상 10~20%, 꽃·장식 10~15%처럼 범위로 보여 줍니다. 수치가 다른 이유는 조사 대상뿐 아니라 장소와 식음료를 묶는지, 꽃과 장식을 나누는지, 세금·서비스료를 별도 항목으로 두는지가 다르기 때문입니다. 어느 표를 그대로 복사하기보다 같은 분류로 다시 묶어야 비교할 수 있습니다.

![카나페와 음료가 놓인 리셉션은 식음료 비중에 서비스 인력과 식기 범위가 포함되는지 확인하게 합니다](/images/canape-reception-02.jpg)

## 예비비 10%를 포함한 100% 배분안

아래 표는 실행 항목을 90%로 제한하고 예비비 10%를 총액 안에 포함한 시작점입니다. 합계는 100%이며 특정 항목을 늘리면 다른 항목에서 같은 비율을 줄입니다.

| 항목 | 비중 | 포함 범위 |
| --- | ---: | --- |
| 장소·시설·기본 대여 | 25% | 예식·연회 공간, 테이블·의자, 기본 장비 |
| 식사·음료·케이크 | 20% | 케이터링, 음료, 디저트, 서비스 인력 |
| 사진·영상 | 9% | 촬영, 편집, 결과물 |
| 꽃·장식 | 7% | 부케, 센터피스, 조명, 사인물 |
| 음악·엔터테인먼트 | 5% | 진행, 음향, 연주·공연 |
| 의상·뷰티·예물 | 7% | 의상, 수선, 액세서리, 헤어·메이크업, 예물 |
| 플래닝·당일 진행 | 4% | 계획과 당일 코디네이션 |
| 교통 | 3% | 신랑·신부, 하객, 업체 이동 |
| 인쇄물·주례·행정 | 3% | 초대장, 식순, 주례, 허가 항목 |
| 선물·답례품·숙박 지원 | 3% | 감사 선물과 필요한 숙박 지원 |
| 세금·서비스료·팁 | 4% | 별도로 표시될 수 있는 부대 항목 |
| 예비비 | 10% | 인원 변화, 초과시간, 날씨 대응, 추가 대여 |
| **합계** | **100%** | 실행예산 90%와 예비비 10% |

예비비는 남는 돈이 아니라 아직 이름이 붙지 않은 의무 항목입니다. Zola의 [Wedding Budget Checklist](https://www.zola.com/expert-advice/all-the-items-that-make-up-a-wedding-budget)는 세금·팁·서비스료·초과시간과 예상 밖 대여를 별도로 보라고 조언합니다. 계약서의 포함 범위가 확정될 때까지 예비비를 장식이나 의상 업그레이드에 옮기지 않는 편이 안전합니다.

![저녁 파티 공간은 음향·조명·운영 인력과 초과시간 조건을 별도 항목으로 점검해야 합니다](/images/after-party-bar-01.jpg)

## 우선순위에 따라 비중을 옮기는 법

하객 경험이 우선이면 식음료를 5%p, 교통을 1%p 늘리고 장식 3%p, 의상·뷰티·예물 1%p, 선물 1%p, 인쇄·행정 1%p를 줄일 수 있습니다. 사진·영상이 우선이면 해당 항목을 4%p 늘리는 대신 꽃·장식 2%p, 음악 1%p, 선물 1%p를 줄입니다. 파티가 핵심이면 음악·엔터테인먼트 3%p와 식음료 2%p를 늘리고 낮은 우선순위에서 합계 5%p를 옮깁니다.

원칙은 세 가지입니다. 첫째, 예비비 10%는 고정합니다. 둘째, 늘린 비율과 줄인 비율을 항상 같게 맞춥니다. 셋째, 하객 수가 확정되기 전에는 인원에 따라 변하는 식음료·교통·인쇄물의 최종 배분을 잠급니다.

## 한국에서 적용할 때 확인할 조건

| 확인할 조건 | 비중표에 반영할 내용 |
| --- | --- |
| 견적 범위 | 가구·식기·음향·조명·설치·철거·청소 포함 여부 |
| 인원 조건 | 최소 보증 인원과 최종 인원 확정일 |
| 세금과 서비스 | 세금·서비스료·팁이 포함인지 별도인지 |
| 외부 업체 | 지정 업체와 반입 제한, 보험·보안 조건 |
| 시간 | 장소·촬영·음향·진행 인력의 초과시간 기준 |
| 날씨 | 실내 대체 공간, 텐트·바닥재·냉난방 책임 주체 |
| 교통 | 차량 대기, 주차, 진입 허가와 지연 시 연장 조건 |

장소의 기본 제공 범위에 실내 대체 공간과 음향·조명·가구가 어디까지 포함되는지 확인한 뒤, 포함되지 않은 항목만 각 비중에 배치해야 중복 계산을 줄일 수 있습니다.

## 요약

총예산의 10%를 예비비로 고정하고 나머지 90%만 실행 항목에 배분하세요. 해외 자료의 비율은 분류 방식이 달라 그대로 더할 수 없으므로 같은 항목으로 재분류해야 합니다. 우선순위가 바뀌면 같은 비율을 다른 항목에서 옮기고, 계약서의 세금·서비스·초과시간·날씨 조건이 확정되기 전에는 예비비를 사용하지 않는 것이 핵심입니다.
