"주례 없이 하고 싶은데 뭘 넣어야 하나요"는 요즘 가장 많이 듣는 질문입니다. 해외에서는 종교 없는 세리모니가 이미 기본이라 식순의 뼈대가 정리되어 있습니다. 미국 The Knot과 Joy의 세리모니 가이드를 바탕으로 세 가지 상황별 식순을 분 단위로 만들었습니다. 그대로 쓰거나, 표시된 자리만 바꿔 쓰면 됩니다.

## 해외 세리모니의 뼈대

[Joy의 세리모니 순서 가이드](https://withjoy.com/blog/wedding-ceremony-order-of-events/)에 따르면 종교 없는 세리모니는 보통 20~30분이고 순서는 이렇습니다: 입장 → 환영 인사(2~3분) → 낭독(선택, 편당 2~5분) → 진행자의 말(3~7분) → 서약(3~8분, 각자 1~2분) → 반지 교환(2~3분) → 유니티 세리모니(선택, 3~5분) → 성혼 선언(30초) → 키스 → 퇴장(2~3분).

[The Knot의 비종교 식순 가이드](https://www.theknot.com/content/secular-nondenominational-wedding-ceremony-scripts)는 낭독과 유니티 의식을 환영 인사 바로 뒤에 두라고 권하고, "두 사람의 이야기 → 결혼에 대한 생각 → 서약 → 반지 → 선언"으로 이어지는 **이야기 중심 구조**도 소개합니다. 한국 예식과 가장 다른 점은 **주례사가 없고, 그 자리에 두 사람의 서약이 들어간다**는 것입니다.

## 식순 1 — 주례 없는 한국식 세리모니 (35분)

양가 부모님이 모두 한국 분이고, 주례 대신 사회자 한 명이 진행하는 경우입니다.

| 시간 | 순서 | 메모 |
| --- | --- | --- |
| 0:00 | 개식, 혼주 입장 (양가 부모님) | 어머니 촛불 점화를 넣으려면 여기 |
| 0:04 | 신랑 입장 → 신부 입장 | 아버지 동반 또는 양가 부모님 동반 |
| 0:08 | 환영 인사 (사회자 2분) | 하객에게 두 사람 소개 |
| 0:10 | **두 사람의 이야기** (사회자 또는 친구 3분) | 주례사 대신. 만난 이야기, 서로의 좋은 점 |
| 0:13 | **서약** (각자 1~2분, 직접 쓴 글) | 읽어도 됩니다. 외우지 마세요 |
| 0:17 | 반지 교환 | 사회자가 짧게 의미를 말하고 교환 |
| 0:19 | 성혼 선언, 키스 | |
| 0:20 | 양가 부모님께 인사 | 큰절 또는 포옹 — 가족이 정합니다 |
| 0:24 | 축가 또는 축사 1건 (4분) | 둘 다 넣으면 35분을 넘깁니다 |
| 0:28 | 행진, 퇴장 | 꽃가루·버블 등 |
| 0:30 | 단체 사진 | 가족 → 친구 순 |

바꿔도 되는 자리: 촛불 점화, 축가, 부케 토스. 바꾸지 않는 게 좋은 자리: 서약과 부모님 인사. 이 둘이 주례사의 빈자리를 채웁니다.

## 식순 2 — 두 나라 가족이 함께하는 세리모니 (40분)

한쪽 가족은 한국식 격식을, 다른 쪽은 서양식 서약 중심을 기대하는 경우입니다. 원칙은 **양쪽 의식을 한 번씩, 언어는 번갈아**입니다.

| 시간 | 순서 | 언어 |
| --- | --- | --- |
| 0:00 | 개식, 혼주 입장 | 한·영 짧게 |
| 0:04 | 신랑·신부 입장 | — |
| 0:08 | 환영 인사 (2분) | 사회자가 두 언어로 각 1분 |
| 0:10 | 낭독 1 — 신부 측 가족·친구 (3분) | 그 사람의 언어 |
| 0:13 | 낭독 2 — 신랑 측 가족·친구 (3분) | 그 사람의 언어 |
| 0:16 | **서약** (각자 2분) | 각자 모국어. 상대 언어로 한 문장 덧붙이기 |
| 0:20 | 반지 교환 | 사회자 두 언어 |
| 0:22 | **유니티 의식** (4분) | 샌드 세레모니·캔들·핸드패스팅 중 하나 |
| 0:26 | 성혼 선언, 키스 | 두 언어로 한 번씩 |
| 0:27 | **양가 부모님께 인사** | 한국 측 큰절, 상대 측 포옹 — 각자 방식 |
| 0:31 | 축가 또는 축사 (4분) | |
| 0:35 | 행진, 퇴장 | |

언어 규칙: 안내는 짧게 두 언어로, 감정이 실리는 대목(서약·낭독)은 말하는 사람의 언어로만 하고 번역은 식순표나 화면 자막으로 처리합니다. 모든 문장을 두 번 말하면 식이 두 배로 길어지고 하객은 절반을 듣지 않습니다.

## 식순 3 — 짧은 세리모니 + 긴 리셉션 (20분 + 2시간 30분)

세리모니는 핵심만, 나머지는 파티로 가져가는 해외식 구조입니다. 하객이 100명 이하이고 대관 시간이 3시간 이상일 때 맞습니다.

**세리모니 (20분)**: 입장(4분) → 환영 인사(2분) → 서약(4분) → 반지 교환(2분) → 성혼 선언·키스(1분) → 부모님께 인사(3분) → 퇴장(2분). 낭독·축가·유니티 의식은 모두 리셉션으로 옮깁니다.

**리셉션 (2시간 30분)**: 칵테일 아워(30분, 사진 촬영 병행) → 입장·퍼스트 댄스(10분) → 디너(60분) → 축사 2~3건(15분, 각 3분 이내) → 케이크 커팅·부케 토스(10분) → 애프터 파티(45분 이상).

이 구조의 전제는 세리모니와 리셉션을 **같은 공간에서 연속으로** 할 수 있고, 식순을 커플이 정할 수 있다는 것입니다. 1~2시간 단위로 회전하는 홀에서는 리셉션 자체가 없습니다.

## 식순 4 — 실제로 진행된 한국식 2부 예식 (2023년 10월, 세빛섬)

위 세 가지가 "설계도"라면, 아래는 서울 한강의 한 웨딩홀에서 실제로 진행된 식순입니다. 신랑·신부 이름은 가렸습니다. 주례 없이 사회자가 진행했고, 1부 세리모니 뒤 2부 리셉션이 같은 홀에서 이어진 구조라 식순 1과 식순 3의 중간 형태입니다.

| 구분 | 순서 | 내용 |
| --- | --- | --- |
| 식전 | 리허설 | 신랑·신부 리허설, 사회자 미팅 |
| 식전 | 리셉션 | 하객 응대 |
| 1부 | 장내 정리 | 사회자 주의 정돈 멘트 |
| 1부 | 개식 선언 | |
| 1부 | 신랑·신부 동시 입장 | 아버지 동반 입장 대신 두 사람이 함께 |
| 1부 | 맞절 | 신랑·신부가 마주 보고 인사 |
| 1부 | 혼인 서약 | 신랑·신부가 직접 낭독 |
| 1부 | 예물 교환 | |
| 1부 | 성혼 선언 | 사회자 진행 |
| 1부 | 축사 | |
| 1부 | 감사 인사 | 신부 부모님 → 신랑 부모님 → 내빈 |
| 1부 | 행진 · 폐식 선언 | |
| 촬영 | 사진 촬영 | 가족·친지 → 친구 |
| 2부 | 장내 정리 | 2부 시작 멘트 |
| 2부 | 재입장 | 신랑·신부 |
| 2부 | 케이크 커팅 | |
| 2부 | 건배 제의 | 신랑·신부 |
| 2부 | 테이블 인사 | 신랑·신부가 테이블을 돌며 인사 |
| 종료 | 정산 | |

눈여겨볼 점 세 가지입니다. **동시 입장**(신부를 "건네는" 장면 대신 두 사람이 함께 걷는 해외식 선택), **직접 낭독하는 혼인 서약**(주례사의 빈자리를 채우는 핵심), 그리고 **감사 인사의 순서**(신부 부모님 → 신랑 부모님 → 내빈). 2부의 재입장·케이크 커팅·건배·테이블 인사는 식순 3의 리셉션을 한국식으로 압축한 형태입니다.

이 예식에서 사회자가 읽은 성혼선언문은 아래와 같습니다. 주례가 없을 때 성혼 선언은 사회자가 읽고, 서명란에 두 사람이 서명하는 방식으로 "선언"의 무게를 지킵니다.

> **성혼선언문**
>
> 지금 여러분이 축복해 주시는 가운데 신랑 ○○○ 군과 신부 ○○○ 양은 그 일가 친척과 친지를 모신 자리에서 일생 동안 고락을 함께할 부부가 되기를 굳게 맹세하였습니다. 이제 두 사람이 성스러운 부부가 되었음을 여러분 앞에 엄숙하게 선언합니다.
>
> 20○○년 ○○월 ○○일 — 서명 ________

국제 커플이라면 같은 문장을 영어로 한 번 더 읽는 대신, 선언문을 두 언어로 인쇄해 두 사람이 함께 서명하는 쪽이 자연스럽습니다.

## 유니티 의식 고르기

세 식순 모두에 넣을 수 있는 "하나 됨"의 상징 의식입니다. Joy가 정리한 선택지는 캔들 점화, 샌드 세레모니, 와인 나누기, 나무 심기, 핸드패스팅입니다.

- **샌드 세레모니**: 두 색 모래를 한 병에 붓습니다. 양가 부모님이 먼저 붓고 두 사람이 마지막에 부으면 "두 가족"의 의미가 됩니다. 국제 커플에 가장 잘 맞습니다.
- **유니티 캔들**: 양가 어머니가 켠 초로 두 사람이 큰 초를 켭니다. 한국식 촛불 점화와 자연스럽게 이어집니다.
- **핸드패스팅**: 두 손을 리본으로 묶는 켈트 전통. "tie the knot"의 어원입니다.

## 한국에서 적용할 때 확인할 조건

| 확인할 것 | 왜 중요한가 |
| --- | --- |
| 식순을 커플이 정할 수 있는지 | 정해진 식순만 되는 홀에서는 위 세 가지 모두 불가능합니다 |
| 사회자가 두 언어로 진행 가능한지 | 식순 2의 전제 |
| 세리모니 시간이 35~40분 허용되는지 | 20분 회전 홀에서는 식순 1·2가 잘립니다 |
| 유니티 의식용 테이블·소품 반입이 되는지 | 샌드·캔들은 바람과 불 규정을 확인 |
| 세리모니 뒤 같은 공간에서 리셉션이 이어지는지 | 식순 3의 전제, 3시간 이상 |

예를 들어 서울 한강의 세빛섬 컨벤션홀은 영어·한국어 이중 언어 진행이 가능하고 여유 있는 예식 시간(3시간 이상)으로 세리모니와 리셉션을 같은 홀에서 이어 갑니다. 홀을 고를 때 "식순을 이렇게 바꿔도 되나요"라고 위 표 중 하나를 보여 주면 답이 바로 나옵니다.
